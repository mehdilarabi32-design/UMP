# 📂 File Organizer Tool v1.0

> **Effortlessly clean, group, and structure your messy directories in seconds!**

**File Organizer Tool** is a lightweight, multi-language desktop application built to organize cluttered folders (Downloads, Desktop, Documents) into clean, categorized subdirectories. Designed with precision, privacy, and speed in mind.

---

### ✨ Key Features

- 🚀 **One-Click Organization:** Instantly sort files into dedicated folders: *Images, Videos, Audio, Documents, and Others*.
- 🌐 **7 Languages Supported:** Seamless interface switching between **English, Arabic, French, Spanish, Chinese, Russian, and German**.
- 🔒 **Stealth & Custom Folder Modes:** Choose between standard folder structures or ultra-discreet, hidden transparent folders.
- 🎨 **Custom Windows Icons:** Auto-applies native system icons to organized subfolders for maximum visual clarity.
- ⚡ **Lightweight & Portable:** Standalone executable — no setup or installation required!
